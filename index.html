Connect to GitHub

The repo is the database. Your token is stored only in this browser and is sent only to api.github.com.

  1. Open github.com → fine-grained tokens → Generate new
  2. Repository access → Only select repositories → past-lives
  3. Permissions → Repository permissions → Contents → Read and write
  4. Generate, copy the github_pat_… string, paste it below
